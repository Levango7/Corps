# ADR-002: 采用 Better Auth 重建认证层

- **状态**：Accepted（2026-08-22，用户拍板「Better Auth 管身份 + 保留 wid 令牌」）
- **提交**：高见远（首席架构师）｜依据：Spec §4 认证锁定 Better Auth、§10 认证约束
- **关联**：ADR-003（Stripe 计费）｜OPEN-DECISIONS（argon2id 偏差）

---

## Background（背景）

初版后端脚手架为跑通而用了**自定义 JWT + argon2 + 自定义 sessions 表**（`lib/jwt.ts` / `lib/argon2.ts` / `lib/auth.ts` / `web/app/api/v1/auth/*`），与 Spec §4「认证 = Better Auth」**偏离**。本次把实现重新对齐回已锁定的 Spec。

多租户隔离依赖 PostgreSQL RLS：`SET LOCAL app.workspace_id = <wid>`，wid 需从请求上下文取得。Better Auth 管「用户身份 + 会话」，不直接理解「工作区」概念，因此需要一个调和方案。

## Decision（决策）

1. **身份与会话归 Better Auth**：用 `better-auth@1.3.28` + `prismaAdapter(prisma, { provider: "postgresql" })`，启用 `emailAndPassword`（注册/登录/会话/登出/邮箱校验全交由 Better Auth）。Better Auth 接管 `users / sessions / accounts / verifications` 四张表（由 `@better-auth/cli generate` 产出精确模型）。
2. **保留 workspace 作用域 wid 令牌**：登录/注册后，服务端用现有 `lib/jwt.ts` 签发一个**嵌入 wid + role 的短效 access JWT（15min）**，供工作区 API 与 RLS 取上下文。该令牌与 Better Auth 会话cookie并存——Better Auth cookie 负责「你是谁」，wid 令牌负责「当前在哪个工作区 + 角色」，二者职责分离、互不替代。
3. **Workspace / Member 模型与三角色 RBAC 原样保留**（owner/admin/member 在 `Member.role`），不引入 Better Auth organization 插件（避免数据模型迁移与 RLS 适配风险）。
4. **注册串接**：`/api/v1/auth/register` 先调 `auth.api.signUpEmail` 建用户+会话，再建 workspace + owner member，最后签发 wid 令牌返回。
5. **路由挂载**：Better Auth 标准端点挂 `/api/auth/[...all]`（`toNextJsHandler`）；业务注册/登录挂 `/api/v1/auth/*`，内部调用 `auth.api`。

## Consequences（后果）

- 正面：认证安全由成熟库兜底（会话轮换/CSRF/安全cookie/密码哈希），对齐 Spec；wid 令牌维持 RLS 隔离不变，跨租户 404/403（AC-03/04）不受影响。
- 负面 / 偏离：
  - **密码哈希偏差**：Better Auth 1.3 email-password 默认用 **scrypt**，非 Spec §4/§10 锁定的 **argon2id**。Better Auth 稳定版未暴露 argon2 哈希钩子。→ 记入 OPEN-DECISIONS，MVP 用 scrypt（仍强），后续评估自定义密码 hasher 插件或回退原生 argon2。
  - **模型变更**：移除自定义 `Session` 表，改为 Better Auth 的 `sessions / accounts / verifications`；`User` 增加 `emailVerified`、密码字段名对齐 Better Auth（`password` ↔ `@map("password_hash")`）、`avatar_url` ↔ `image`。需 `npx prisma migrate dev` 重建迁移（不可在沙箱执行）。
  - 需本机执行 `npx @better-auth/cli generate` 校准 Prisma 模型字段（沙箱无法 install，代码按 1.3 标准形态手写，需本机 generate 校验）。

## 验收映射

- AC-01 注册建用户+工作区+owner+令牌：由 register 路由满足。
- AC-03/04 跨租户隔离：wid 令牌 + `getWorkspaceContext` + RLS 不变。
- Spec §10 认证约束（HTTPS only / secure+httpOnly cookie / 15min access）：Better Auth 会话 cookie + wid 令牌 15min 满足。
