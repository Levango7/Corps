# ADR-012: 文档实时协同降级为"本地编辑 + 版本历史"模式

> 状态：已采纳
> 日期：2026-10-04
> 关联：ADR-001（多租户隔离）、ADR-006（RLS 激活机制）、`server/collab/`、`web/components/CollaborationProvider.tsx`、`docs/ROADMAP-2026Q4.md` §1.1

## 背景

文档编辑器的实时协同（Yjs + WebSocket）在**前端已完整实现**：
`CollaborationProvider.tsx` 创建 Yjs Doc + `WebsocketProvider` + `IndexeddbPersistence`，
维护 connecting/online/offline 三态，并检测离线超 7 天提示用户核对合并结果。

但**服务端从未部署**：

- `server/collab/` 只有 `persistence.ts` 与 `y-websocket-server.ts` 两个源文件
- **没有 `package.json`**、不在 pnpm workspace、不在 `docker-compose.yml`
- 前端 WS URL 默认回退 `ws://localhost:1234`，在任何部署形态下都连不上

实际效果：协同链路"连不上，静默降级到 IndexedDB 本地缓存"。用户看到的是
PresenceIndicator 显示离线，但不清楚**为什么**离线、**是否**会影响自己的数据。

## 决策

**明确降级为"本地编辑 + 版本历史"模式，暂不收编协同服务端。**

具体动作：
1. 对外表述与文档统一为"本地编辑 + 版本历史"，不再把"实时协同"作为已交付能力
2. `server/collab/` 源码**保留**（它是可用的服务端实现，属"待收编"而非"待删除"）
3. 后续收编的前置条件见下节

## 理由（按决策维度）

### 风险可靠性——这是决定性因素

`server/collab/` 的 WS 服务端**没有任何鉴权**。`y-websocket-server.ts` 接受连接后
按文档 ID 直接读写 Yjs 文档，不校验：

- 连接者是否登录
- 连接者是否属于该文档所在工作区

一旦按现状收编并暴露端口，**任何知道文档 ID 的人都能读写任意工作区的文档内容**——
这是跨租户数据泄漏，与 ADR-001 确立的"引擎级租户隔离、不依赖应用代码自觉"
直接冲突。**先收编后补鉴权 = 用一个卖点功能换一个 P0 漏洞。**

### 产品定位

corps 的核心卖点是**"讨论结论自动落位成任务"**——决策记录、任务看板、双向回链。
文档中心的定位是"团队公约/新人手册沉淀"，属于**静态知识**而非高频协同编辑场景。
对 5–30 人团队，"本地编辑 + 版本历史 + 公开只读分享"已覆盖绝大多数真实需求。

### 可持续性

`ROADMAP-2026Q4.md` §3 已宣告 **90 天内不新增能力域**。收编协同服务端属于
"新增可部署组件 + 新增鉴权域"，与之冲突。在质量基线 burn-down（零覆盖 643 / T3 157 /
契约豁免 205）尚未收敛时引入新组件，会稀释打磨期的注意力。

### 收益性

收编的完整成本包括：打包、compose 服务、**令牌鉴权设计 + 实现 + 回归测试**、
断线重连与冲突合并的浏览器级 E2E。而收益是"文档可多人同时编辑"——
在试用阶段（2–3 个团队、每团队数人）的边际价值低。

### 兼容性

降级**不改变任何数据格式**：文档正文仍存 `documents.markdown`，
版本历史仍在 `document_versions`。前端 `CollaborationProvider` 保留不动，
未来收编时只需配置 `NEXT_PUBLIC_COLLAB_WS_URL` 并补齐服务端鉴权，**无迁移成本**。

## 后续收编的前置条件

满足全部条件后才考虑收编：

1. `server/collab/` 补 `package.json`，纳入 pnpm workspace 与 CI（含 lint/test）
2. **实现令牌鉴权**：复用 `lib/auth.ts` 的 JWT 校验，连接时校验
   `document.workspaceId` 与 token 中的 `wid` 一致，并断言属于该工作区成员
3. 补浏览器级 E2E：双端并发编辑 → 冲突合并 → 断线重连
4. 在 `docker-compose.yml` 增加服务并收敛端口到 `127.0.0.1`
5. 完成上述后，本 ADR 状态改为"已取代"，另立 ADR 记录新方案

## 影响

- 文档中心对用户的呈现为"编辑 → 保存 → 版本历史"，**不展示协同在线状态**
- `.env.example` 中 `NEXT_PUBLIC_COLLAB_WS_URL` 标注为"未配置即本地编辑模式"
- 质量基线中不新增协同相关条目
