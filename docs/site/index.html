三步本地运行

克隆仓库、安装依赖、启动开发服务器，几分钟即可在本地跑起来。

bash 
# 1. 克隆仓库
git clone https://github.com/Levango7/Corps.git
cd Corps/web

# 2. 安装依赖
pnpm install --frozen-lockfile

# 3. 启动开发服务器
pnpm dev

首次运行需配置 PostgreSQL 与环境变量，完整步骤详见 README.md 与 Vercel 部署指南。
