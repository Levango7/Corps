> **状态**：提案；立项 2026-11-12 业主批（选项 A 分期）。A1 实施前仍须先过 §8 待核（OFD 选型等）；「不写产品代码、不改模块注册表」的禁令随立项批解除，注册表改动按 L1 口径（默认「更多」）。
> 依据：survey §11 P1 lane（差距表「公文管理/公文交换/OFD 版式＝缺口（最大单点）」）、
> [POSITIONING.md](POSITIONING.md)（2026-10-23 拍板口径）、PRODUCT-DESIGN-2026Q4 §5（默认 6+可选）、
> FUNNEL-METRICS §2.1（WAW/CORE_EVENTS，ACCEPTED）。
> 口径（C 口径同执行）：能力＝已实现工程事实或本文明确标注的「估算/待核」；不含「支持/计划」式承诺。

## 1. 一句话

> 面向政府口协同办公标的的**公文管理 + 交换**能力：收发文登记、拟稿→审核→签发流程、
> OFD 版式预览、交换留痕——不做通用版式编辑器、不替代电子公文交换系统。

## 3. 与定位的兼容性（先过 POSITIONING 评审三问）

- **L1 首屏入口 ≤10**：公文默认进「更多」，不进首屏；注册表加 id 后 `DEFAULT_VISIBLE_MODULE_IDS` 不动（并集 31→32 的单测断言随 PR 更新）。
- **L4 必填配置 = 0**：开箱只需工作区已有成员与既有角色；不预置部门/权限/印章。
- **L3 首次价值时间**：公文不在楔子链路，不承诺 L3 收益、也不拖慢注册→首任务路径（空状态引导沿用既有模式）。
- **反模式检查**：不是「飞书有我们也要」（证据＝3 份全文级品目，survey §11）；不是强制引导；不是管理员强推。
- **排期规则兼容性**：POSITIONING §5 冻结的是「横向补功能」；公文是政府口垂直 lane 的**入场券**（不做则最大品目出局），属开新 lane 不是补广度。（2026-11-12 业主认可，本论证生效。）

## 4. 对象模型草案（到「要哪些数据」，不写 schema）

公文（文号、标题、密级、紧急程度、来源/去向、状态：拟稿→审核→签发→交换/归档）、
流程意见（审核意见留痕，含人/时/结论）、交换记录（收发时间、通道、操作人）、
OFD 附件（版本、哈希、预览产物引用）。

- 迁移全 additive（与待发迁移口径一致）。
- 新表必须进 `db/rls-activate.sql` 与 `scripts/check_rls_posture.py` 的覆盖口径
  （挂钩 G1a/C-01：新增表即新增租户隔离面，不进静态门=缺口自现）。

## 6. 推荐：A 分期（A1＝B 的能力集＋A 的骨架；A2＝拟稿/签发流＋归档）

- **A1 验收判据（可测）**：政府口全文级品目覆盖 ≥2/3；A1 数据（采用率/品目命中）才准 A2 立项复核。
- **A2 上首屏条件（2026-11-12 裁）**：规则＝公文周活跃工作区渗透率（公文周活跃 wid / WAW，Asia/Shanghai 周界，同 WAW 口径）连续 N 周 ≥ 阈值；阈值与 N 随 A1 采用率数据拍定，本批不拍脑袋；未达标前永远在「更多」（沿用 L2 数据支撑规则）。
- 分期理由：工期最长不能等（survey §11），但首版不碰拟稿流＝把 OFD 预览这个最大技术未知项先落地验证。

## 7. 事件面与 WAW（防 `create_comment` 覆辙）

- 新事件草案：`gov_doc_created` / `gov_doc_signed` / `gov_doc_exchanged`。
- **本期不直接进 CORE_EVENTS**：改 CORE_EVENTS＝改 ACCEPTED 口径（FUNNEL-METRICS §2.1），须业主拍板。
- 本期只进事件白名单＋埋点契约门禁（与 #56 同模式：白名单事件必须有 emit 站点＋反向棘轮），
  否则公文行为在 WAW 口径里等于不存在。
- WAW 挂钩方式（2026-11-12 裁）：独立渗透率口径，本期不进 CORE_EVENTS；改 CORE_EVENTS＝改 ACCEPTED 口径，须业主另拍。

## 8. 待核项（不凭记忆给结论）

1. OFD 解析/预览选型（国内版式软件生态；自研/组件/服务端转换）——标「待核」，能力清单不写「支持 OFD」。
2. 电子签章/盖章＝制度＋密码应用双重业主侧（密评映射 C 表已标缺口）。
3. 与既有电子公文交换系统对接口径（#17 品目含「交换系统」）＝业主侧接口事实。
4. 等保条款原文核（COMPLIANCE-MAPPING §E.1）：密级/留痕字段设计等条款核完才定稿。
5. 短信提醒（#17 品目含）＝既有通知面扩展还是独立通道，待核。

## 9. 不做

通用版式编辑器、视频会议、CRM（PRODUCT-DESIGN §3 非目标同样适用）；不动首屏 10 入口；
不改楔子链路；不为公文新增加必填配置。
