# 信息架构整合方案 · 2026Q4（2026-10-03）

> 方向（用户拍板）：**功能上不做减法，做整合。** 33 个功能域全部保留，
> 但产品呈现从"33 个并列的工具"变成"一个有结构的工作台"。
> 本文档第一层已落地；其余各层按自用验证的痛点优先级排队。

---

## 为什么"平铺"是问题

一个 5–30 人的团队成员打开工作区侧栏，原来看到的是 **28 个同级入口**：
决策、邮件、音视频、OKR、多维表……每个都同样显眼。后果：

- 新用户找不到入口的"重心"，产品楔子（讨论→决策→任务）被淹没；
- 高频项（看板/任务/消息）和一年点不了一次的项（模板/表单）占同样的视觉位；
- 用户心智里它是"33 个小工具的集合"，而不是"一个协作产品"。

---

## 第一层（已落地，2026-10-03）：侧栏归组 + Cmd+K 直达

### 侧栏：28 项 → "核心 5 项 + 4 个命名组 + 管理组"

| 组 | 成员（原有功能一个不少） |
|---|---|
| （无标签·核心） | 概览、看板、我的任务、决策记录、消息(IM) —— 产品楔子四件套 |
| 协作 | 会议、会议纪要、审批、公告、日历、联系人 |
| 知识 | 文档、Wiki、白板、多维表格、表单、回收站 |
| 规划 | OKR、工作流、模板、工时 |
| AI 能力 | AI 工具、洞察、知识问答、日报、公告草稿 |
| 管理（原有） | 成员、计费、分析、设置 |

实现：`app/[locale]/w/[wid]/layout.tsx` 的 `navGroups` 重组（NavGroup 机制现成，
零新组件）；新增 4 个分组词条（zh/en：groupCollaboration/groupKnowledge/groupPlanning/groupAI）。
Viewer 过滤逻辑不受影响（仍按 href 前缀隐藏管理入口）。

### CommandPalette（Cmd+K）：5 项 → 29 项全功能直达

- 导航项从 5 个补到全部 29 个（复用 `nav.menu.*` 词条，零新增翻译量）；
- 空态只列核心 8 项（防长列表）；输入时**本地即时匹配导航项**（翻译文案 contains）
  排在 API 搜索结果之前——长尾功能"知道名字就能到"，不再依赖找分组。

> 整合原则由此确立：**高频走侧栏首屏，长尾走 Cmd+K，低频走分组。**

## 第二层（提案，按自用痛点优先级排队）

### 2.1 AI 统一入口（五页 → 一页）

现状：ai-tools / insight / knowledge-qa / daily-report / announcement-draft 五个独立页面，
共用 Sparkles 图标并列在侧栏——用户要理解"5 个 AI 页面分别是什么"。

提案：合并为 `/w/{wid}/ai` 一个页面，五块能力变成页内 tab（或分区）：
「对话工具 | 洞察报告 | 知识问答 | 日报 | 公告草稿」。旧路由 301 重定向保留，
API 与底层能力零改动。侧栏 AI 组从 5 项缩为 1 项。
**归属判断**：纯路由层整合，风险低；建议自用验证"AI 组里哪几个真的会被点"后做。

### 2.2 通知中心（三个通知面 → 一个）

现状：站内通知（notifications 页）+ 通知偏好 + 邮件通知 + 公告，四个相关但分离的面。

提案：通知中心页内分区「@我 / 任务提醒 / 公告」，通知偏好挂进设置；
公告发布后自动进通知流（公告与通知在数据上本就是近亲）。

### 2.3 会议-日历-纪要三件套贯通

现状：meetings / calendar / meeting-minutes 三个页面独立。

提案：日历视图内点会议 → 抽屉直接显示该会议的纪要与参会人（数据已关联：
Meeting ↔ MeetingMinutes 外键已存在），不必跳三页。纯视图层整合。

### 2.4 任务体系分层呈现

现状：OKR（objectives/key-results）、里程碑、任务三层数据都有表和页面，但彼此
跳转断裂——任务详情看不到"它属于哪个目标"。

提案：任务详情页顶部加面包屑链「目标 → 里程碑 → 本任务」（现有外键即可拼出），
OKR 页点关键结果直接过滤相关任务。**这一条直接强化产品楔子**：讨论→决策→任务
的"任务"从此有了"为什么做"的上下文。

### 2.5 文档协同服务端收编（功能性缺口，非 UX）

`server/collab` 是文档实时协同的服务端（前端 `CollaborationProvider` 连
`NEXT_PUBLIC_COLLAB_WS_URL`），但从未部署（无 package.json、不在 compose）。
收编 = 补 package.json + compose 服务 + 令牌鉴权；完成前协同为
IndexedDB 离线降级态。**这是"整合"清单里唯一的功能性必做项。**
