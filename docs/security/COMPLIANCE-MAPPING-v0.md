## 0. 口径规则（C 口径的执行细则）

1. **能力清单（投标层）**＝已实现的工程事实，每条可指认 repo 路径/门禁；不含承诺、不含「支持/计划」。
2. **验收附件（证据层）**＝实测读数（CI run / 脚本输出 / 一次性容器记录），编号 E-xx；无读数的格子留空并标「待补链」。
3. **标准原文列**只放可核引用（条款号＋标题）；未联网核对的一律标「待核」，不凭记忆引用原文。
4. **责任分担**：SaaS 形态下物理环境等整类归云服务商（Vercel/Neon）；「不适用」≠「符合」，测评时按责任分担矩阵出证。
5. 状态枚举：`已实测`（本仓有读数）/ `工程事实`（代码在、无独立读数）/ `待激活`（生产未通电）/ `缺口` / `制度类-业主侧` / `云服务商责任`。
