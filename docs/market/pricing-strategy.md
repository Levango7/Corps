# corps 定价策略建议

> 日期：2026-08-23 ｜ 基于：ADR-003 + SPEC OPEN-DECISIONS

---

## 1. 协作 SaaS 定价模型调研

| 产品 | 免费层 | 起步付费 | 定价模型 | 备注 |
|------|--------|----------|----------|------|
| Trello | ≤10看板 | $5/人/月 | 按人/月 | 功能限制为主 |
| Linear | 无免费 | $8/人/月 | 按人/月 | 无免费层 |
| Notion | 个人免费 | $10/人/月 | 按人/月 + 按空间 | 个人免费 + 团队付费 |
| 飞书 | ≤500人免 | ¥50/人/月 | 按人/月 | 门槛极高 |
| ClickUp | 一定功能 | $7/人/月 | 按人/月 | 功能分层 |
| Teambition | 10人免费 | ¥25/人/月 | 按人/月 | 国内对标 |
| **corps** | **≤10人免费** | **¥59/人/月** | **席位计费** | 席位实时同步 |

### 关键结论

1. **免费层阈值**：10人免费是行业"慷慨"水平（Trello 按看板、Notion 个人、Teambition 10人）
2. **起步付费**：$8-12/人/月是行业标准区间，corps 的 ¥59（≈$8）在区间下限
3. **席位计费**：corps 的独特优势——成员数变更自动同步 Stripe quantity，竞品多为手动

## 2. corps 推荐定价

### 2.1 三档定价

> 产品定位锁定 5–30 人中小团队（SPEC §1）。定价层席位上限不超出该范围；超出 30 人的团队走 Enterprise 询价，不在自助订阅档内。

| 套餐 | 价格 | 席位 | 核心功能 |
|------|------|------|----------|
| **Free** | ¥0 | ≤10人 | 任务看板 + 基础 RBAC + 单工作区 + 暗色主题 |
| **Starter** | ¥59/人/月 | 11–30人 | Free 全包 + 决策记录（版本留痕） + 多工作区 + Cmd+K 搜索 |
| **Pro** | ¥89/人/月 | 11–30人（高级功能档） | Starter 全包 + 决策协同编辑 + API 访问 + 优先支持 + SSO |

> Pro 与 Starter 席位区间相同（均覆盖 11–30 人），差异在功能集而非人数。需要 SSO/API/协同编辑的 5–30 人团队按功能升级到 Pro，无需等到 31+ 人。

### 2.2 定价依据

- Starter ¥59/人/月 = SPEC.md 建议的 ¥59（锚定 $8） + ADR-003 倾向"¥59/人/月起步档"
- Pro ¥89/人/月 = 高级功能档，面向 5–30 人目标范围内需要 SSO/API/协同编辑的团队，对标 Notion $10 + SSO 溢价；席位上限保持 30 人，与产品定位一致
- 免费层 10人 = SPEC.md 锁定的"免费限 10人"

### 2.3 计费粒度

- 按**活跃成员数**（非注册数）计费
- 席位变更 Stripe webhook 自动同步 quantity（AC-08）
- 当月新增成员按比例计费（prorated）

## 3. 中国市场支付通道建议

### 3.1 当前状态（ADR-003 OPEN 项）

- MVP：Stripe（test mode → 生产跨境）
- 生产：**首选微信支付/支付宝**

### 3.2 推荐路径

| 阶段 | 支付通道 | 理由 |
|------|----------|------|
| MVP | Stripe test mode | 快速验证订阅逻辑 |
| Beta | Stripe 跨境（香港/新加坡商户）| 验证真实付费 |
| 公发 | 微信支付 + 支付宝 + Stripe 备选 | 国内直连最优 |

### 3.3 微信/支付宝接入路径

- Starter 启用时通过 `paymentProvider` 抽象切换
- 签约：微信商户平台 + 支付宝开放平台
- 接口：Native支付/JSAPI支付 → 生成订阅二维码/跳转
- 催缴：webhook `invoice.payment_failed` → 短信/模板消息提醒

## 4. 转化漏斗建议

```
访客 → 注册（免费层） → 激活（14天内创建首个任务） → 付费（超10人触发） → 留存（30天回访）
 ↓           ↓                        ↓                      ↓                     ↓
目标:      目标:                    目标:                  目标:                 目标:
LP访问      注册转化>15%              激活率>60%              付费转化>8%            月度留存>70%
```

### 4.1 关键转化节点

| 节点 | 触发 | 优化杠杆 |
|------|------|----------|
| 注册 → 激活 | 14天内创建首个任务 | Onboarding 引导（AC-07: 15分钟内"创建首个任务"） |
| 激活 → 付费 | 工作区超 10 人 | 席位上限提示 + 升级弹窗 + 免费试用 Pro 7天 |
| 付费 → 留存 | 30天活跃 | 周报邮件（本周任务完成数+决策记录数） + 团队协作网络效应 |

### 4.2 付费触发点

1. 第 11 人接受邀请 → 提示升级 Starter
2. 需要 API 访问 / SSO / 决策协同编辑 → 提示升级 Pro（按功能触发，非按人数触发）
3. 团队规模 >30 人（超出产品定位） → 引导至 Enterprise 询价，不在自助订阅档内

## 5. 敏感定价红线

- **绝不**在 MVP 阶段收"隐藏费用"
- **绝不**在免费层偷偷降级性能
- **绝不**锁定数据——降级回 Free 层后数据仍可访问（只读）
- 价格调整至少提前 30 天通知
