## 1. 十月（30 天）：从「能跑」到「在跑」

### 1.1 正式部署（本周内，唯一最重要的事）

- 一台 2C4G VPS + `docker compose`（代码零改动：README DEPLOY 章节即 runbook）
- 域名 + HTTPS，回填 `SMOKE_TARGET_URL` → Smoke 从"临时隧道绿"变"正式实例绿"
- **验收**：README 实例行从"临时隧道验证"改为真实 URL；连续 7 天 Smoke 无红
- 注意：当前临时隧道 URL 随本机进程消亡，关机即开始每 15 分钟报红——
  正式部署完成前，要么保持本机隧道进程存活，要么先 `gh variable delete SMOKE_TARGET_URL`

### 1.2 灰度验证写策略

- `WRITE_POLICY_MODE=shadow` 跑一轮真实流量，收集 `[write-policy] shadow-deny` 日志
- **验收**：无误杀路径，或误杀路径全部有解释；切回 enforce

### 1.3 找 3 个真实试点团队（5–15 人）

- 打开埋点（lib/analytics 已具备），定义漏斗：注册 → 建工作区 → 邀人 → 首个任务 → 7 日回访
- **验收**：3 个团队真实使用 ≥2 周；拿到注册→激活→7 日留存数字
- **这个数字决定 §3 的分岔走向，没有它一切规划都是猜测**

## 3. 十一月：宽度收敛与补课

**冻结宣告**：即日起 90 天内**不新增能力域**（不新增表、不新增 route 域、不新增 AI 能力）。
例外：修 bug、安全收口、试点团队点名要的缺口。

### 3.1 宽度收敛表决（保留 / 冻结 / 下线）

对以下域逐一表决，**至少下线或冻结 2 个**，维护带宽让给核心三场景（任务看板 + 决策记录 + 任务内轻沟通）：

- `mail`（邮件账户收发）
- `webrtc`（LiveKit 音视频）
- `okr`（目标与关键结果）
- `database`（多维表格）
- `desktop` + `harmonyos` + 三条移动 CI（0 用户展示性资产）
- `server/collab`（孤儿：无 package.json、不在 workspace、不在 compose——要么收编要么删除）

### 3.2 AI 能力收窄

17 项 → **3 项有付费价值的**：决策草稿生成、周报/复盘自动生成、跨任务洞察。
其余转 labs 或下线（每项都是真实的 LLM 账单 + 维护面）。

### 3.3 关键路径覆盖补课

`lib/permissions.ts`、`lib/ai/orchestrator.ts`、`lib/payments/*`、`lib/im/ws-server.ts`
补到 ≥60% 行覆盖，functions 覆盖率 CI 阈值从 55 上调。

### 3.4 major 升级批次（issue #32）

按 #32 的执行序：Prisma 7 → TypeScript 6 → Stripe 22，各自独立提交独立 revert。
TS6 单独升级已被实测否决（Prisma 6 client interop 破坏），必须配套。

## 4. 十二月：按数据分岔（试点留存给出答案）

门槛毫不含糊：**至少 2 个团队付费 + 试点团队次月留存 ≥60%**。

### 路 A（达标）：企业化
- SSO/SAML（ADR-009 F4 已论证）、审计日志（security 已有 PENTEST 基础）、数据导出合规包
- 解决主体问题：注册公司 / 合伙 → 营业执照 + ICP 备案 → 解锁微信/支付宝通道（UI 文案已按此口径）
- 认知：这条路瓶颈从来不是代码，是主体与资质

### 路 B（不达标）：开源 + 自托管优先
- 把 RLS 双层防御 + NOBYPASSRLS 加固 CI + 带 --self-test 的门禁脚本 打包为
  **可复用的"多租户安全脚手架"**对外输出——这是本项目最稀缺的差异化资产
- 产品本身降为示例集；工程声誉变现为影响力，好过一个人扛着 25 万行无人使用的 SaaS

---

## 5. 不做什么（负面清单）

- 不再新增 i18n 之外的功能域，不接新的第三方 SaaS 集成
- 不做"再造一个 IM"（进 Slack/飞书/企微的**进入侧**集成除外）
- 不在无生产实例时讨论 SLO 承诺
- 不在试点数据出来前启动企业版功能开发
