# 判据（红因集合）：
#   NEW_<RULE>        基线外首见的 (文件, 规则)     -> CI 红：新违反，真修或显式登记

# 为什么是棘轮不是一刀切：上线时全仓已存在真实违反（邮件/导出 HTML 不接受 var()、

# 为什么是「文件 + 规则 + 处数」而不是「文件:行号」：web/ 有并行会话在改，行号会漂，
# 任何往上/往下插一行都会让一批登记项错位成「新增」——那正是天天误叫的死法。
